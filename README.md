# BrightPen Academy — faithful recreation

This project recreates the supplied BrightPen Academy screenshots as a responsive, working single-page website.

## Run

No build step is required.

- Open `index.html` directly in a browser, **or**
- serve the folder with any static server, e.g. `python3 -m http.server`.

## Functional interactions

- Navigation anchors scroll to sections.
- Contact Us opens a small dropdown.
- Enroll buttons open a working enquiry modal.
- The enquiry form validates and shows a local confirmation message.
- Gallery arrows/dots work as a carousel.
- The map image links to the BrightPen Academy location in Google Maps.
- Responsive mobile layout and menu are included.

## Assets

The supplied screenshots were used as the visual source. The classroom photos and map appearance are cropped from the supplied reference screenshots so the recreation stays visually faithful to the references.
